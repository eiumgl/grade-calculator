Grade Calculator

Name: Andre Miguel Fabello  
Section: IT3R4

Description
A simple Java program that accepts a student's name
and numerical grade, then displays the grade and
remark. It identifies excellent grades, passing
grades, failing grades, and invalid inputs.

Requirements
- Java Development Kit (JDK)

How to Run
1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Compile the program:
   javac GradeCalculator.java
4. Run the program:
   java GradeCalculator

Features
- Accepts a student's name.
- Accepts a numerical grade.
- Displays the student's grade and remark.
- Checks for invalid grades.
